# ПР1. Ответы на контрольные вопросы

1.В Python код выполняется построчно, если ошибка спрятана где-то в конце, про неё не узнать, пока программа до туда не дойдёт. А в C# компилятор сначала читает весь код целиком и проверяет его. Если найдёт хоть одну синтаксическую ошибку, программа вообще не запустится. То есть C# находит ошибки до запуска, а Python во время.

2.dotnet run сначала собирает проект, компилируя все .cs файлы, а потом запускает то, что получилось.

3.bin/ — это куда компилятор кладёт готовую скомпилированную программу. obj/ — временные файлы, которые нужны во время сборки. Это не исходный код, а результат работы компилятора на моём компьютере. Их не нужно хранить в Git, потому что они каждый раз создаются заново командой dotnet run.

4.git commit выполняет сохранения изменений на моем компьютере. git push отправляет эти изменения на GitHub, в удаленный репозиторий. 

5.Конкатенация — это склейка строк через плюс: firstName + " " + lastName. Интерполяция — это когда я пишу $"{firstName} {lastName}" и переменные подставляются прямо в текст через фигурные скобки.

6.Если оба числа int, то и результат будет int, результат не округляется, дробная часть просто отбрасывается. Чтобы получить точный результат, нужно превратить хотя бы одно число в double.

7.const — это переменная, значение которой я задаю один раз, и потом оно не меняется. Если попытаюсь перезаписать, компилятор выдаст ошибку. Обычную переменную можно менять когда угодно. Пример: const double Pi = 3.14159; — число пи никогда не меняется, поэтому константа тут идеально подходит.

8.Top-level statements — это когда можно писать код сразу, без лишней обёртки в виде класса и метода Main. Компилятор сам её добавляет. А во втором варианте пришлось бы писать class Program { static void Main() { ... } }. Отличие только в краткости и удобстве.
